# MundoMarino — Enciclopedia Marina y Conservación

Aplicación web interactiva desarrollada con **HTML5**, **CSS3** (Tailwind CSS + Animaciones personalizadas de olas y burbujas) y **React 18**, inspirada en el artículo de divulgación ambiental de **EcologíaVerde**.

---

## 🌊 Estructura del Proyecto

```
carpa/
├── index.html        # Página principal y punto de montaje de React
├── css/
│   └── styles.css    # Efectos visuales de profundidad marina, olas y burbujas
├── js/
│   ├── data.js       # Base de datos completa de animales marinos y conservación
│   └── app.js        # Componentes interactivos de React 18 (búsqueda, filtros, modal)
└── README.md         # Documentación de la página web
```

## ✨ Características y Funcionalidades

1. **Sección Principal (Hero)**:
   - Texto introductorio fiel a la información proporcionada.
   - Efecto de burbujas flotantes en CSS puro y ondas marinas animadas.
   - 4 métricas clave del océano (+70% superficie terrestre, 97% agua del planeta, >80% inexplorado, 50-80% oxígeno producido).

2. **Importancia Vital del Océano**:
   - Tarjetas de impacto: regulación meteorológica global, sustento humano, sumidero de CO2 y megabiodiversidad.
   - Generador interactivo de datos curiosos con React.

3. **Características de los Animales de Agua Salada**:
   - Adaptaciones de osmorregulación, respiración, hidrodinámica y resistencia a la presión.
   - Cuadro comparativo entre organismos pelágicos (necton), bentónicos y plancton.

4. **Catálogo de Especies Interactivo (React)**:
   - Buscador en tiempo real por nombre, hábitat o dieta.
   - Filtros por taxonomía: Mamíferos, Peces, Reptiles e Invertebrados.
   - Filtro rápido para especies en peligro de extinción UICN.
   - Fichas biológicas modales completas con fotografías en alta definición, hábitat, dieta y curiosidades.

5. **Especies en Peligro Crítico de Extinción**:
   - Panel de alerta con estados de la Lista Roja de la UICN (Vaquita marina, Tortuga carey, Ballena franca del Atlántico Norte, Foca monje, etc.).
   - Amenazas principales y acciones urgentes de conservación.

6. **Medidas de Conservación Ciudadana**:
   - Acciones prácticas y sostenibles para proteger los mares.
